# Система управління розкладом в університеті

Цей проєкт реалізує просту систему для керування розкладом занять у вигляді коду на **TypeScript**. Його мета — продемонструвати використання union types, type alias та масивів у контексті моделювання розкладу університету.

## Основні можливості

- **Визначення типів**: створені type alias для днів тижня, часових слотів і типів занять, а також структурні типи для викладачів, аудиторій, курсів та заньать.
- **Масиви даних**: підтримка списків професорів, аудиторій, курсів та розкладу.
- **Додавання даних**: функції для додавання нового професора, аудиторії, курсу та заняття з перевіркою на конфлікти.
- **Пошук і фільтрація**: пошук вільних аудиторій у певний час, перегляд розкладу конкретного викладача.
- **Валідація та обробка конфліктів**: перевірка, чи вже зайняті професор або аудиторія на вказаний час, зі зворотнім повідомленням про тип конфлікту.
- **Аналітика**: підрахунок відсотка використання аудиторії та визначення найпопулярнішого типу заньать у розкладі.
- **Модифікація розкладу**: можливість переназначити занятя в іншу аудиторію або скасувати заняття.

## Структура проєкту

- `src/index.ts` — основний файл із усіма визначеннями типів, масивами та функціями.
- `dist/index.js` — згенерований JavaScript після компіляції TypeScript (`tsc`).
- `tsconfig.json` — конфігураційний файл TypeScript з базовими параметрами: `target` (ES6), `module` (commonjs), `strict`, а також шляхи до вихідних та згенерованих файлів.
- `package.json` — опис проєкту та скрипти для запуску компіляції.

## Запуск

1. Встановіть залежності (за наявності доступу до npm):

```bash
npm install
```

2. Скомпілюйте TypeScript у JavaScript:

```bash
npm run build
```

3. Після компіляції згенерований файл `dist/index.js` містить усі функції й може бути використаний у Node.js чи браузері.

## Приклад використання

```ts
import {
  addProfessor,
  addClassroom,
  addCourse,
  addLesson,
  getProfessorSchedule,
} from './dist/index.js';

// Створюємо професора, курс і аудиторію
addProfessor({ id: 1, name: 'Іван Петренко', department: 'Математика' });
addClassroom({ number: '101', capacity: 30, hasProjector: true });
addCourse({ id: 1, name: 'Алгебра', type: 'Lecture' });

// Додаємо заняття у розклад
const result = addLesson({
  courseId: 1,
  professorId: 1,
  classroomNumber: '101',
  dayOfWeek: 'Monday',
  timeSlot: '8:30-10:00',
});
console.log('Заняття додано:', result);

// Отримуємо розклад професора
const schedule = getProfessorSchedule(1);
console.log(schedule);
```

## Ліцензія

Проєкт доступний без спеціальних обмежень та може бути використаний як навчальний приклад.
